A very little project description

This project is a little trial to show how easy it is to define some
new language constructs in scheme.
Here I try to show how to define a object oriented extension with
the possibility to define classes, objects and interfaces, as well as calling their methods. 
The definition also includes member variables and the possibility to distinct if a method / member variable is private, protected or public.

I have to mention that the implementation up to now does not take care on performance issues or optimization.
